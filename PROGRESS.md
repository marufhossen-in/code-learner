### How the code got in, and why the numbers are trustworthy

`tools/audit/tmp/mkcode.mjs` takes a spec of snippets, **runs each one** with node, and emits the
lesson `code` block with the captured stdout pasted into the block as a comment. So the figure a
learner reads next to the snippet is the figure the machine printed. The lessons now carry things
like: `W=2 R=1 W+R=3 N=3 -> stale 351 of 1000` (a quorum that only *equals* N still reads stale);
`fact(10)` needing 10 frames; `fib(20)` at 21891 calls versus 39 with a Map; a BFS printing
