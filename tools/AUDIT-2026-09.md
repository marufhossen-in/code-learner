## Pass 2 (2026-09-26) — re-authoring engine + good-hub repair

Root cause of the tangled lessons: ~68 of 135 hubs were generated from a rhyme-template chant
family (headings, keyterm defs, exercise bodies were all vocabulary play, not facts), and
earlier machine sweeps then pasted ledger sentences into otherwise *good* hubs.

Triage (measured, `/tmp/audit/tier*.txt`): 70 hubs need wholesale re-authoring, 12 partial, 8 light.

Re-authoring pipeline (new): `src/content/_specs/<hub>.mjs` (hand-authored facts, bilingual)
→ `tools/reauthor.mjs` → canonical `index.ts` + `lessons/*.ts`, engine-enforced anatomy
(WHAT → facts → keyterms → WHY → HOW steps → code/tryit → misstep → visual/diagram →
3 exercises + 4 quiz questions, or the tool refuses). Visuals: hub's interactive lab when one
exists (SIM map), else a stage diagram generated from that lesson's own steps.

Done: **arrays** (8 lessons: contiguous-block model, holes vs undefined, cost table for
push/pop/shift/splice, five loop forms, map/filter/reduce contracts, find/includes/NaN,
comparator + stability, memory/clone/Set-vs-scan) — strict gate **0 issues**, 4 interactive labs
+ 4 stage diagrams + 2 Try-it-yourself runners, 56 rebuilt assessment items.

Good-hub repairs this pass: filler paras 101 · list items 98 · keyterms 36 · table rows 5 ·
rewritten hints/explanations 87 · titles 509 files · chains 148 · visuals for 21 hubs.

Remaining census (strict gate, per category): good hubs — 304 terse exercise prompts (house
style, needs re-phrasing not re-writing), 282 blocks missing Bengali (authoring queue), 59
open-answer items with no gradable answer, 13 filler strings, 11 chain gaps, 8 lessons without
a visual. Chant hubs — 520 filler, 503 no visual, 395 missing Bengali, 169 terse prompts,
9 open answers; all of these disappear as each hub is replaced by `reauthor`.

w3schools parity read (approx.): they publish 30-60 pages per big track (HTML ~60, JS ~70,
Python ~50, SQL ~30) each = tutorial + exercise + code challenge; our largest tracks are 8-9
lessons. So we are **ahead** on structure per lesson (bilingual body, interactive lab, worked
mechanics, graded quiz with explanations, reference cards, roadmap, projects, interview) and
**behind** on breadth — the coverage expansion (8-9 → 25-40 lessons per flagship track) is the
next phase, hub by hub, using the arrays spec as the template.
